Serve AMP Reader over HTTP

This example cannot run when opened directly with a file:// URL because browsers block JavaScript module imports from local files.

From the AllMediaProcessor directory, run:

npm run preview:runtime

Then open:

http://127.0.0.1:4178/dist-runtime/AMP-READER-USAGE.html

Your deployed website already uses HTTP or HTTPS, so this restriction does not apply after deployment.
