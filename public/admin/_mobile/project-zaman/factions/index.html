Purpose

This index maps the faction hierarchy of Project ZAMAN. Parent notes carry shared history and system-level context. Child notes carry focused identity, behavior, and role.

Writing Rule

Use parent notes when describing shared origin, hierarchy, faction-wide consequences, or reconciliation.

Use child notes when describing one faction’s beliefs, behavior, territory, symbols, NPCs, quests, or visual identity.
