Typography and Written Language

Tags: project-zaman symbols symbol language naming working

Purpose of this folder

Two related things: the in-world writing systems (which language belongs to whom, and what that ownership means), and the typographic direction for the game itself — titles, item text, UI, subtitles.

The first is already half-designed. The second is untouched.

The Naming Framework — Established

From Project Zaman, Core Principle 01:

LanguageReserved forStatus
ArabicCore metaphysical truths, world concepts, protagonist-facing ideasDeclared, no terms written yet
HebrewThe cult, its rituals, ranks, doctrines, chambers, subjects, esoteric terminologyIn use — Gibborim, Noam
GreekThe public-facing layerIn use — Anthropos, Axios
NoneThe protagonistDeliberate. The [[MC

Gibborim extends this: Axios’ clinical designations (Subject-001, Subject-002) begin as neutral archival identifiers and are then absorbed into Gibborim’s ceremonial framework. Within the inner order a number is never merely a number — it carries sequence, proximity, failure, inheritance, and perceived worth.

So the vault already has three registers of written language, each with a different relationship to truth:

  • Greek speaks to the public and is meant to be read
  • Hebrew speaks inward and is meant to exclude
  • Axios’ clinical script claims to be neutral and is the most dishonest of the three

The Gap

Arabic is assigned the most important category — core metaphysical truths and everything the protagonist faces — and currently contains zero terms. Every named thing in the vault is Hebrew, Greek, or plain English.

This is the single largest hole in the naming system, and it matters more than it looks: the framework’s whole point is that the protagonist stands outside the cult’s language. That only lands if there is a language he stands in.

Concepts that would sit in the Arabic register if it existed: Immaculate Thought, Soul Fission, the Oscillation of Eras, the Desert, the Hope Entity, and the Irreversibility Principle.

Open Questions

In-world

  • Does Zaman itself belong to the Arabic register, and can characters say it?
  • Should established concepts be renamed into Arabic, given Arabic names alongside their English ones, or left as they are with Arabic reserved for new material?
  • Who in-world speaks the Arabic register? If nobody does, is it the narration’s language rather than any character’s?
  • Do the Order of the Oasis and The Mirage have their own written voice? The Order claims the founder’s legacy, so its documents would be formal and preservationist; Mirage field records would be hurried and damaged.

Typographic

  • What does the title treatment look like — and does it use one script or two?
  • Item and note text: this is a Soulslike, so item descriptions carry most of the lore. Do they read as Axios’ clinical reports, as recovered Mirage field notes, or as an unattributed narrator?
  • Does any in-game text appear in a script the player cannot read? A powerful option, given that the story is about being defined in a language you were never given.
  • Legibility floor for subtitles and UI at the target resolutions.

Constraint already established

Language in this project is a form of ownership. Gibborim names in order to possess; Axios numbers in order to neutralize; the protagonist is left unnamed in order to be excluded. Any new naming decision should answer the question who does this give power to.
