Color Language

Color Language

Tags: project-zaman symbols symbol color working

Purpose of this folder

The meaning color carries in Project ZAMAN, and the rules that keep it consistent across art, UI, and environment. A color only means something if it is withheld elsewhere.

Colors Already Used in the Vault

Every entry below is drawn from an existing note. Nothing here is a decided system yet — it is the raw material a system could be built from.

ColorWhere it already appearsSource

The Pattern Worth Noticing

The two cult colors are already an opposed pair with assigned meanings, and Alyna wears both at once. Whether that is deliberate is currently unanswered, but it is the most interesting color fact in the vault: the one genuinely good person in the story wears the cult’s two colors as a uniform, and it is precisely that uniform that lets her move unseen through their building.

Worth deciding whether this is coincidence or the spine of the whole color system.

Working Faction Palettes

These are practical starting points, not final canon.

FactionCore colorsMeaning
The Order of the OasisDeep green, worn brass, off-white cloth, dark leatherProtected life, discipline, inherited duty, and controlled survival.
The MirageSun-faded blue, ash gray, weathered black, pale clothDistance, dust, uncertainty, fieldwork, and truth seen through distortion.

The two child factions should share traces of the parent Oasis palette, but each should damage or preserve it differently. The Order keeps the mark controlled and upright. The Mirage lets it waver, break, or fade.

Open Questions

  • Is there a color for the protagonist? He is excluded from the cult’s naming system. Excluding him from its palette as well would be consistent — but then what is he? Absence of color, or a color the cult has no use for?
  • What separates Subject-001 from Subject-002 visually? They share an origin and need to read as different at a glance, especially since Subject-002 is only ever seen at a distance.
  • How final are the two successor palettes? The Order and The Mirage now have working palettes, but they still need testing against character designs, environments, and UI readability.
  • Does the Desert have a palette that changes? The Hope Entity establishes that its light, weather, and scale shift with Subject-001’s coherence. That is a color system waiting to be written.
  • What does a colliding era look like in color? The one chance to make temporal desynchronization readable without dialogue.
  • Is red reserved? If red belongs only to the shadow form, it cannot be used for UI, blood, or enemies without weakening it.

Suggested Structure

Rather than one note per color, this folder may work better as:

  • Core Palette — the small set of colors with fixed meaning, and what each is forbidden to be used for
  • Faction Palettes — Anthropos, Gibborim, Axios, the Order, The Mirage
  • Character Palettes — including whether the MC has one
  • The Desert Palette — state-driven rather than fixed
  • UI and Readability — where meaning has to give way to legibility

Rule to hold the system together

Assign each color one meaning and then protect it by not using it elsewhere. A palette in a story like this fails through overuse, not through poor choices.
