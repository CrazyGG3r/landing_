Corrective bones: I will try it with ARP. Seems harder to implement but I do know it will be very easy to adjust. Just need to get better at rigging and constraints again.

Already spent like 1-2 weeks on final semester to excel this, it shouldn’t go to waste, hopefully I’d recall things when i get thru them again.

Rigging:

Started with implementing an advanced rig.
Advantage: Very realistic results.
Disadvantage: The rig is heavily operated with BBone mechanism. BBone is blender-only feature, so its incompatible everywhere else.
Workaround: There is an addon that converts BBone into standard bones. The only condition is to bake all the animations that is dependent on it.
