Reference Library

Reference Library

Tags: project-zaman creative creative references working

Purpose of this folder

Source material to consult while writing and building: research, terminology, visual reference, and technical documentation.

Distinct from Creative/Influences, which records works this project is responding to. This folder is for things you look up.

Research Needed

Areas the vault already depends on but has not yet grounded:

Period research — early 20th century
Institutional life, orphanages and their real record-keeping, domestic service and what a uniform meant socially, newspapers and how a story was placed or suppressed, harbor and dock work, underground and anonymous publishing. Alyna’s entire campaign in Story Structure rests on how small presses actually operated and how they were traced.

Language
Hebrew terms and transliteration for the Gibborim register. Greek for Anthropos and Axios. Arabic for the declared-but-empty register described in Symbols/Typography. Worth recording the source and transliteration for every term adopted, so nothing gets silently mangled later.

Fraternal orders
Real structure, degrees, and secrecy practices, to keep the three-layer cult believable and to be clear about where the fiction departs from the reality.

Clinical and archival writing
Axios’ voice depends on it. Real case notes, subject numbering conventions, and laboratory record formats would make its neutrality genuinely unsettling rather than stylized.

Technical
Engine documentation once the engine is chosen; the New Input System referenced in Project Zaman.

Reference Entry Format

Visual Reference

Character and sigil reference images live in _Media/_Images and are embedded directly in the character notes. Many still use default Pasted image <timestamp> filenames, which works at the current scale but will not survive growth.

Worth deciding soon:

  • A naming convention — for example char-mc-adult-01.png, sigil-gibborim-01.png
  • Whether external reference (photographs, period images, other games’ screenshots) is stored in the vault or linked
  • Attribution for anything not originally created for this project

Suggested Notes for This Folder

  • Period Research
  • Language and Terminology — the running glossary, with sources
  • Fraternal Order Structure
  • Clinical Writing Reference

Record the source, not just the fact

Anything adopted into canon from research should keep a pointer back to where it came from. In a project this dependent on terminology in three languages, an unsourced term is a future error.
