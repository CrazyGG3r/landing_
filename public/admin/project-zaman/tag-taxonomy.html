Tag Taxonomy

Tags: project-zaman index home reference active

Purpose

This note defines the tag system used across the Project ZAMAN vault.

Core Rule

Every note should have:

  • #project-zaman
  • One #type/... tag
  • One #domain/... tag
  • One #status/... tag
  • A small number of role, faction, concept, production, or asset tags when they add real browsing value

Do not tag every noun. Tags should describe what a note is, not every word it mentions.

Main Families

FamilyUse
#type/...What kind of note it is: character, faction, concept, event, mechanic, location, index, tracker, production, creative, symbol.
#domain/...Where the note belongs in the vault: characters, factions, lore, narrative, world, production, symbols, creative, home.
#status/...Current state: active, established, working, open, unresolved, undefined, dormant, fractured, partial, mentioned, proposed, deceased.
#role/...Narrative or structural role: protagonist, antagonist, child-faction, parent-faction, emotional-anchor, player-character, authority, overseer, overseen, heir, patriarch, founder, father-figure.
#faction/...Faction ownership or relevance: anthropos, axios, gibborim, head-family, oasis, order-of-the-oasis, mirage, cult, survivors.
#character/...Major character identity tags.
#concept/...High-value concepts only: identity, soul, time, trauma, hope, doctrine, knowledge, protection, denial, chaos, founder-legacy.
#production/...Production tracking: art, design, animation, progress.
#mechanic/...Play-facing mechanical tags: dodge, parry.
#creative/...Creative workspace tags: ideas, influences, references.
#asset/...Visual-reference grouping: concept, 3d-model, composition, abstract.

Primary Areas

Use these indexes when checking whether a tag belongs to a note:

Connection Rule

Use wikilinks for strong conceptual relationships.

Use tags for grouping and filtering.

If a relationship would matter in Graph View, use a wikilink. If it only helps find similar notes, use a tag.
